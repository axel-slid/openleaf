Openleaf keeps papers, slides, code, and agents in one coherent desktop workspace.

- edit LaTeX and compile live PDFs alongside source, diagnostics, and review tools
- build editable PowerPoint files and run Python notebooks without leaving the project
- work with shell, Codex, Claude, and SSH agents across local and remote workspaces
